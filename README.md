# 组备份 · Tabgroup Vault Sidebar

在 Chrome 侧边栏保存和恢复标签组、窗口与会话。使用原生 JavaScript 和 Manifest V3，无需安装依赖或构建。

## 功能

- 保存单个标签组、窗口或全部窗口的会话，保留组名、颜色、标签顺序与固定状态。
- 更新已有备份或另存副本；恢复后继续保留备份。
- 编辑分组与会话，搜索当前页面和已保存内容，选择恢复单个页面、分组或窗口。
- 按站点预览自动分组，确认后应用；支持排序和部分操作撤销。
- 导入、导出 JSON 备份，以及 Markdown、CSV 链接清单。
- 可选关闭窗口时自动保存分组，提供四种主题。

## 安装

1. 下载本仓库 ZIP 并解压，或克隆仓库。
2. 在 Chrome 中打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目目录。
4. 点击扩展图标打开侧边栏。可在扩展菜单中固定“组备份”，方便再次打开。

## 使用

在“当前”中保存标签组，或通过工具栏保存窗口、会话。未命名分组在保存时需要填写名称。

在“已保存”中查看、编辑和恢复备份。会话可以包含多个窗口；恢复会重新打开保存的地址，无法恢复网页中的登录状态、表单输入或滚动位置。受限制的浏览器内部页面会被跳过。

需要换电脑时，导出 JSON，再在另一台电脑导入。JSON 保留分组与会话结构；Markdown 和 CSV 导入后作为链接清单保存。

## 数据与权限

备份和设置保存在当前浏览器配置文件的 `chrome.storage.local` 中。卸载扩展前，请先导出需要保留的备份。导出文件包含网页标题和地址，分享前请检查其中的私人链接。

| 权限 | 用途 |
| --- | --- |
| `tabs` | 读取页面标题和地址，打开、关闭与排序标签页 |
| `tabGroups` | 读取、创建和修改标签组 |
| `storage` | 在本机保存备份和设置 |
| `sidePanel` | 显示扩展侧边栏 |
| `https://www.googleapis.com/*` | 用户主动执行 Google Drive 备份时上传数据 |

Google Drive 是可选功能：当前需要在设置中手动填写账号标记与有效的访问令牌，尚未提供 OAuth 登录界面。“立即同步”会向 Google Drive 上传一份 JSON 备份；当前没有云端下载、合并或自动双向同步。访问令牌保存在本机扩展存储中，不包含在导出的备份里；令牌过期后需要重新填写。

语言设置目前只切换页面语言标记，界面文案仍以中文为主。“统计偏好”目前仅保存开关，没有接入统计服务。

## 开发与验证

扩展可直接加载源码。现有逻辑测试使用 Node.js 内置测试运行器，建议使用支持 ES module 自动识别的 Node.js 22.7+：

```sh
node --test tests/backup-logic.test.js
```

测试覆盖保存、更新、恢复、导入导出、自动分组、搜索、会话编辑和 Drive 上传逻辑。Chrome API 与侧边栏交互仍需在浏览器中手动验证。

```text
manifest.json                扩展配置与权限
background.js                后台事件与关闭窗口自动保存
sidepanel.html / .css / .js   侧边栏界面
src/backup-logic.js           备份与恢复逻辑
tests/backup-logic.test.js    逻辑测试
```
